# 🌐 Muskan Kishnani — Developer Portfolio

Live URL:- https://muskan-portfolio2.netlify.app/

## ✨ Features

- 🌗 **Dark / Light Theme Toggle** — Persistent across sessions using `localStorage`
- 🎞️ **AOS Animations** — Smooth scroll-triggered reveal effects throughout
- 🃏 **Swiper.js Testimonials** — Coverflow carousel for client testimonials
- 📱 **Fully Responsive** — Mobile-first layout using Bootstrap 5.3 grid
- 🎨 **CSS Custom Properties** — Complete theme system with CSS variables
- 🔤 **Google Fonts** — Syne (headings) + DM Sans (body) for a premium feel
- 🧭 **Sticky Glassmorphism Navbar** — Frosted glass effect with backdrop blur
- ⚡ **Project Tabs** — Frontend / Backend / Fullstack categorized project showcase
- 📨 **Contact Form** — Floating label inputs with smooth focus effects
- 🌀 **Background Orbs** — Animated ambient gradient effects

## 🎨 Theme System

The portfolio uses a **CSS variable-based dual theme system**:

| Variable | Dark Theme | Light Theme |
|---|---|---|
| `--bg` | `#080b14` | `#f5f3ff` |
| `--primary` | `#7c3aed` | `#6d28d9` |
| `--accent` | `#06b6d4` | `#0891b2` |
| `--text` | `#f1f5f9` | `#1e1b4b` |
| `--bg-card` | `#111827` | `#ffffff` |

Theme preference is saved to `localStorage` under the key `portfolio-theme`.

## 🚀 Getting Started

No build tools or npm required — it's pure HTML/CSS/JS!

```bash
# 1. Clone the repository
git clone https://github.com/muskankishnani06/portfolio.git

# 2. Open in your browser
cd portfolio
open index.html
```

Or simply open `index.html` directly in any modern browser. ✅
